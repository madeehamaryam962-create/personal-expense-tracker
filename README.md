# 💰 Personal Expense Tracker

A simple Python-based Personal Expense Tracker that helps users calculate their total expenses and remaining money based on their monthly income.

## 📌 Project Overview

The Personal Expense Tracker is a beginner-friendly Python project designed to help users understand and manage their monthly spending.

The program asks the user for their:

- Name
- Monthly income
- Food expenses
- Travel expenses
- Shopping expenses

It then calculates:

**Total Expenses = Food + Travel + Shopping**

**Remaining Money = Monthly Income − Total Expenses**

## ✨ Features

- 👤 Accepts user's name
- 💵 Records monthly income
- 🍔 Records food expenses
- 🚗 Records travel expenses
- 🛍️ Records shopping expenses
- 🧮 Calculates total expenses
- 💰 Calculates remaining money
- 🖥️ Simple command-line interface
